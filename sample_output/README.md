# sample_output/

This folder contains illustrative sample output files generated by NSE-Alpha v1.

| File | Description |
|---|---|
| `signals_2024-12-20.csv` | Sample daily signal file — 30 tickers, 2024-12-20 |
| `backtest_equity_curve_sample.csv` | Sample equity curve from backtest run |

These files are for demonstration only and use realistic but simulated values.
Real output files are written to `outputs/signals/` after running the system.
